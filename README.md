# Nestart Home — website prototype

A 3-page e-commerce prototype for **Nestart Home**, a Malta-based poster and wall-art brand, made for a university marketing project.

- `index.html` — Home: hero, featured categories, value proposition
- `shop.html` — The Art Collection: 3 products with size and frame options, plus the **Virtual Gallery Wall Customiser**
- `about.html` — Our Story, and a contact & collaboration form

Static HTML, CSS and JavaScript with no build step. All poster artwork is original inline SVG (`assets/js/art.js`).
Prototype only: the cart works, but checkout and the contact form are demo-only and don't process anything.
